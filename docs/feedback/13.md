## UX

I want some small UX changes/fixes:
 - We have the nice "double tap to zoom" feature, but double tapping on a country still registers the first tap as the actual click on the country. Instead, the first click should already highlight the country (to keep the app responsive, use the same highlight as hovering on desktop), but only after we _haven't actually_ zoomed it should register the click. So you can double tap on mobile to zoom without clicking on anything. On desktop, we can scroll, so this double click behaviour is not needed.
 - Similar direction as this: When on mobile tapping twice and holding the _second_ tap, it should start a zoom guesture. When dragging up it should zoom in, dragging down it should zoom out. This should be a _smooth_ zoom. 
 - Clicking on any country that was already guessed (without the hidden modifier) shouldn't count as a click. So any country already white, or orange, or red. This makes clicking faster easier if you miss.
 - Maybe: Tapping _just_ on the border (few pixels) of the correct country should maybe count as the correct country. I'm not 100% sure, or it should just ignore your tap the first time. I want _some_ wiggle room for misclicks especially on mobile especially on the smaller countries.

## Language switcher
 - Add the country flag (british flag and dutch flag) to the language switcher. In very small, so it cannot be confused with the actual country you're supposed to be guessing. 

## Mobile Layout

On mobile, the layout gets a little bit messed up on smaller screens. 
 - The dropdown for language and muting/unmuting should be merged into one. 
 - I think the layouy should then become three lines, all aligned to the center: Question number. Then the correct, half correct, incorrect and percentage. And finally the actual country name. 
 - The language switcher and globe icon should be vertically center aligned.
