## Leaderboard

There should be an offline leaderboard in the app. This leaderboard is per configuration. It should be shown on the start screen and the _end screen_ (new). Both start and end screen should be devided into two parts, the left and right. The current start screen should be on the left. The right part should become the leaderboard. For any selection, a leaderboard should exist, and show/store the top 10 scores achieved on this configuration. If there are no scores, it should show an empty leaderboard.

## Completing a quiz

Whenever you complete a quiz, the _end screen_ should open and your score should get added to the leaderboard.

The score between 0 and 100%. 100% is everything correct. Getting it on second guess is counts as half correct. So getting everything in your second guess gives you a score of 50%.

## End screen

The end screen should look very similar to the start screen. It is divided into two halfs, left and right. The left shows a summary of what you just did in the quiz. The right shows the leaderboard with your new score added and highlighted.

The left part should show the following:
 - In large: the percentage you got correct.
 - Three collapsable elements containin the count of the correct, half correct and incorrect counts. Clicking on this uncollapses this element and shows you the full list of the countries you got correct or incorrect.
 - On the bottom there should be a button "back to start" taking you back to the start screen, to try again.
