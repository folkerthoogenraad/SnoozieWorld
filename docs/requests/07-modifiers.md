Selecting the game mode should be a single thing (for now): name to location. Then, we have modifiers below that. Some modifiers are either enabled or disabled. Other modifiers have multiple states.

## Modifiers

Modifiers should be stored on the leaderboard, next to the score, with only their symbols. Clicking on them toggles them to enabled, or the next state in the chain.

Each modifier clicked on should be explained below the modifiers.

### Flag modifier

The flags modifier by default is on "name and flag". Clicking it again it goes to "name only", clicking it again it goes to "flag only". Clicking again, it will go back to normal mode.

 - "Name and flag"
 - "Name only"
 - "Flag only"

Icon: T (for text) + a flag symbol combined, or only the T (text) symbol, then only the flag symbol. Depending on the state.

### Guess count modifier

Normally you get two guesses. With single guess enabled you get only one guess. With sudden death enabled you fail the entire quiz if you get one incorrect.

- Single gues

Icon: A 1. and a skull.

### Hint modifier

Disables the hints when you have an incorrect guess.

Icon: lightbulb

## Score changes

The modifiers do not directly affect the leaderboard. The scores on the leaderboard should be displayed with the modifiers, so you can see what modifiers were used.
