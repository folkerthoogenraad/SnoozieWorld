The explore mode should become a split button, with the second option being a practise mode. This mode uses the "what do you want to quiz" and the gamemode as usual, but ignores the modifiers. It is an attempt to help you learn. What it should do is the following:
 - It should shuffle the list of all the countries
 - Whenever you make a mistake, it should shuffle this new country into the set of countries left, to ask you again. So by the end, the hardest ones you keep getting wrong keep being in the set.
 - Once the whole set is completed, reshuffle all the countries and start again. Repeat until the player stops.
 - The map should only color the country you actually have to click or just clicked, but after that it should return to green. So every guess is pure and from the start.

The only modifier it should not ignore is the flag/text only modifiers. Because we should be able to do that too.

Instead of keeping track of the amount of correct and incorrect, it should only keep track of the current streak. So, how many in a row do you have correct.
